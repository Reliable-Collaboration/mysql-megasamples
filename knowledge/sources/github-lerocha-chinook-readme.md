# Relevant excerpt (paraphrase of the summary returned)
"The Chinook data model represents a digital media store, including tables for artists, albums, media tracks, invoices and customers." Supported: DB2, MySQL, Oracle, PostgreSQL, SQL Server, SQLite. Scripts are obtained from the latest release assets. Media data came from a real iTunes library; customer and employee data were created manually with fictitious names and realistic addresses; sales data was generated randomly over a four-year period. Positioned as a modern alternative to Northwind for demos and ORM tests. The README does not list row counts or a license (the license is in LICENSE.md).
