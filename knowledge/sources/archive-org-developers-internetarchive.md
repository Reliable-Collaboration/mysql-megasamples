# Relevant excerpt
* The `internetarchive` library is a Python API and command-line interface (`ia`) for searching, downloading, uploading and managing archive.org content; install with `pip install internetarchive`; `ia configure` stores S3-like access/secret keys; `ia upload` and `ia download` are the transfer commands.
* Items need `mediatype`, `title` and `collection` metadata; the library is distributed under AGPL-3.
