# Relevant excerpt
> The titanic and titanic2 data frames describe the survival status of individual passengers on the Titanic. The titanic data frame does not contain information from the crew ... The principal source for data about Titanic passengers is the Encyclopedia Titanica. ... One of the original sources is Eaton & Haas (1994) Titanic: Triumph and Tragedy, Patrick Stephens Ltd, which includes a passenger list created by many researchers and edited by Michael A. Findlay. ... These data were obtained from Robert Dawson, Saint Mary's University ... Thomas Cason of UVa has greatly updated and improved the titanic data frame using the Encyclopedia Titanica and created a new dataset called titanic3. These datasets reflects the state of data available as of 2 August 1999. Some duplicate passengers have been dropped, many errors corrected, many missing ages filled in, and new variables created.

Variables (titanic): pclass, survived, name, age, embarked, home.dest, room, ticket, boat, sex. References Simonoff (1997) J. Statistics Education 5(1).
