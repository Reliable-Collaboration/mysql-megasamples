# Licenses

## Concepts
* [GNU AGPL v3 (internetarchive Python library / ia CLI)](agpl-3-0.md) - Strong copyleft licence of the maintainer-side upload tool; never shipped in the image and never linked by project code, so no obligation attaches to the repository or the image.
* [Apache License 2.0](apache-2-0.md) - Permissive license of dbt-labs/jaffle-shop-classic (seed data + dbt project) and the jafgen generator; requires license copy, change notices and retained attribution notices.
* [BSD 3-Clause ("New BSD") as applied to Sakila](bsd-3-clause-sakila.md) - License of sakila-schema.sql and sakila-data.sql (Oracle); the manual and sakila.mwb are NOT under it.
* [BSD 3-Clause (generic, for build-time Python packages)](bsd-3-clause.md) - Permissive licence of lxml (declared BSD-3-Clause) and sqlparse (BSD classifier) as reported by PyPI metadata; these run only at build time and are not shipped in the image.
* [Creative Commons Attribution 4.0 International (CC BY 4.0) - UCI Iris](cc-by-4-0.md) - Attribution-only license that UCI applies to its Iris distribution; requires creator credit, license notice and modification notice; no share-alike.
* [Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)](cc-by-sa-3-0.md) - Copyleft data/content license used by the Employees (test_db) and Lahman Baseball databases; requires attribution and same-license redistribution of adaptations.
* [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](cc-by-sa-4-0.md) - Share-alike copyleft license for content; applied to Stack Exchange posts contributed on or after 2018-05-02 and to Wikipedia text (dual-licensed with GFDL).
* [CC0 1.0 Universal (public domain dedication) - palmerpenguins](cc0-1-0.md) - No-rights-reserved dedication used for the Palmer Station penguin data; no legal obligations, but the authors request citation and adherence to the LTER data access policy.
* [City of Chicago Data Terms of Use](chicago-data-portal-terms.md) - Chicago permits reuse of portal data but requires a verbatim disclaimer wherever a derivative application is published, plus an indemnity.
* [Citi Bike / NYCBS Data Sharing Policy](citibike-data-use-policy.md) - Lyft Bikes and Scooters' licence for Citi Bike trip data; it grants broad use but expressly forbids publishing or distributing the data as a stand-alone dataset, which blocks shipping it in this image.
* [Divvy Data License Agreement](divvy-data-license.md) - Lyft Bikes and Scooters' licence for City-of-Chicago-owned Divvy data; grant and restrictions are word-for-word the Citi Bike policy, including the stand-alone-dataset prohibition.
* [Enron email corpus — public record status and CMU distribution terms](enron-public-record.md) - The CMU Enron corpus has no license text; it is FERC public-record material redistributed by CMU with a privacy request; this record states exactly what the page says and what is inferred.
* [GNU Free Documentation License 1.3 (GFDL 1.3)](gfdl-1-3.md) - Second license of the Wikipedia text dual license (CC BY-SA 4.0 + GFDL); reusers may pick either; this project relies on CC BY-SA and ships GFDL text for completeness.
* [GNU General Public License v2.0 (or later) - Dell DVD Store 3](gpl-2-0.md) - Copyleft license of the DS3 kit (generators, drivers, build scripts); the data CSVs are program output whose status is an open question.
* [GNU General Public License v3.0 (HammerDB)](gpl-3-0.md) - Copyleft license of HammerDB; relevant only if HammerDB code is redistributed or linked, not for merely running it or shipping data it loaded.
* [Vanderbilt Biostatistics (hbiostat.org/data) permission statement](hbiostat-data-permission.md) - Blanket permission for the datasets hosted by Frank Harrell's group, with a requested acknowledgement line; not a formal open license.
* [Microsoft SQL Server Developer edition EULA (Linux container, ACCEPT_EULA)](microsoft-sql-server-developer-eula.md) - Proprietary end-user terms accepted by ACCEPT_EULA=Y for mcr.microsoft.com/mssql/server; permits design/develop/test/demonstrate use and forbids production use; governs build-time use only, nothing licensed under it is redistributed.
* [MIT License](mit.md) - Permissive license requiring only that the copyright notice and permission notice accompany copies; used by Chinook and the Contoso Data Generator V2 (tool and data).
* [Natural Earth public domain terms](natural-earth-public-domain.md) - Natural Earth vector/raster map data is public domain with no attribution requirement; relevant because WideWorldImporters embeds country/state borders and city locations derived from Natural Earth (and data.gov).
* [NYC Open Data Terms of Use](nyc-open-data-terms.md) - The terms governing NYC Open Data (and therefore TLC trip records) - the FAQ says there are no use restrictions, while the incorporated NYC.gov terms reserve the City's rights; no attribution or share-alike is required.
* [PostgreSQL License (as applied to pgloader)](postgresql.md) - Permissive PGDG licence text carried by dimitri/pgloader: use, copy, modify, distribute for any purpose without fee provided the copyright notice and the two disclaimer paragraphs appear in all copies.
* [Stack Exchange data dump terms (2024 "Data dump access" click-through, ToS clause, archive.org license.txt)](stackexchange-data-dump-terms.md) - The contractual layer around the CC BY-SA licensed Stack Exchange dumps since July 2024 — what the click-through says, what it restricts, and why this project sources the last archive.org dump instead.
* [TPC End User License Agreement v2.2 (dbgen, qgen, dsdgen, dsqgen and derivatives)](tpc-eula.md) - The license on every TPC benchmark tool and on anything merged with it; permits use, modification and no-fee redistribution with the full agreement and a legend, restricts performance-result publication and TPC name use, and is silent about generated data.
* [U.S. Government work (17 U.S.C. Sec. 105) - public domain](us-government-public-domain.md) - Works of the U.S. federal government carry no copyright; applies to the BTS/DOT On-Time Performance data and its lookup tables.
